## Acknowledgments and Third-Party Resources

This project uses open-source libraries and official documentation to implement, simulate, and evaluate the STEER-LINK quantum telemetry receiver. Third-party libraries are acknowledged below.

### Open-Source Libraries

| Library | Purpose | Official Documentation |
|---|---|---|
| Qiskit | Quantum circuit construction and manipulation | https://docs.quantum.ibm.com/ |
| Qiskit Aer | Ideal and noisy quantum circuit simulation | https://qiskit.github.io/qiskit-aer/ |
| Qiskit IBM Runtime | IBM Quantum backend access and circuit execution | https://quantum.cloud.ibm.com/docs/en/guides |
| NumPy | Numerical calculations and reference-model implementation | https://numpy.org/doc/ |
| SciPy | Numerical optimization of rotation angles | https://docs.scipy.org/doc/scipy/ |
| Matplotlib | Circuit visualization and performance graphs | https://matplotlib.org/stable/ |
| Pandas | Tabular result presentation and analysis | https://pandas.pydata.org/docs/ |
| pylatexenc | LaTeX rendering support for circuit diagrams | https://pylatexenc.readthedocs.io/ |
